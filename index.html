Free Database Setup & Cloud Sync

Your translation system uses 100% free database solutions. Choose your preferred mode below:

🗄️

1. IndexedDB (Active by default)

100% Free & Zero Config

Browser-native SQL/NoSQL storage built right into your browser. Persists all custom vocabulary, phonetics, and history across browser reloads without signing up for any accounts.

  • ✓ Zero API keys required
  • ✓ Works offline and directly on GitHub Pages
  • ✓ Instant read/write speed
🔥

2. Google Firebase Firestore

Free Spark Plan (Cloud Sync)

Sync your dictionary across multiple devices and users via Google Cloud's free Firestore NoSQL database (1GB storage, 50,000 reads/day free forever).

  • ✓ Real-time cloud sync across phones & PCs
  • ✓ Free forever under Google Spark tier
  • ✓ Works directly via REST API
⚡

3. Supabase (Free PostgreSQL)

Free Tier (500MB DB)

Connect a free open-source PostgreSQL database with instant REST APIs for team or community dictionary expansion.

  • ✓ Free PostgreSQL cloud database
  • ✓ Secure REST API key integration

Connect Cloud Database (Optional)

Leave on "Local IndexedDB" if you do not want to set up cloud accounts. It works immediately!

💡 How to get free Firebase credentials: Go to Firebase Console (free), create a project, enable "Firestore Database", and copy your Project ID & Web API Key.
💡 How to get free Supabase credentials: Go to supabase.com, create a free project, create a table named tausug_dictionary, and copy your Project URL & Anon Key.

Piper Neural Text-to-Speech (VITS / ONNX)

Run state-of-the-art neural speech synthesis locally inside your browser with WebAssembly & ONNX Runtime Web.

🧠 Neural AI Voice Active
⚡

100% Client-Side & Private

Runs entirely inside your browser using WebAssembly. No server GPU or cloud API keys required, making it 100% free forever and private.

💾

Offline OPFS Caching

Once downloaded, models are cached in your browser's Origin Private File System (OPFS). Future visits load instantly with zero data usage.

🗣️

Phonetic Articulation

Tausug vocabulary is translated and voiced through custom phonetic mappings, giving natural prosody even for non-standard dialect sounds.
